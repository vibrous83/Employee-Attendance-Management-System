# Employee-Attendance-Management-System
Developed a web-based employee attendance management system to simplify daily attendance recording and employee attendance monitoring within a company. The system provides two user roles: Admin and Employee, each with different access permissions and functionalities.

## Insight:
- Developed CRUD (Create, Read, Update, Delete) functionality for managing employee data and attendance records.
- Developed employee attendance features, including clock-in, clock-out, leave requests, and sick leave submissions.
- Enabled employees to track attendance records, view attendance history, and monitor attendance statistics.
- Provided administrators with employee data management, attendance monitoring, leave management, and attendance report generation.

## Outcome:
Successfully developed a centralized attendance management system that helps administrators manage employee attendance records and enables employees to record and monitor their daily attendance more efficiently.
